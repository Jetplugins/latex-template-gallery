\hero{Learning from data}{Lecture 03 / Introduction to statistical reasoning}
\section*{Learning goals}Explain a model in words, distinguish a parameter from an observation, and interpret a simple least-squares estimate.
\section{From observations to a model}A model is a deliberate simplification. Identify what is observed, what is unknown, and which assumptions connect them.
\subsection*{Definition: residual}For observation $i$, the residual is $r_i=y_i-\hat{y}_i$. It records the difference between an observed and a predicted value.
\section{A worked example}For a constant predictor $\hat{y}_i=c$, minimise
\[
L(c)=\sum_{i=1}^{n}(y_i-c)^2.
\]
Differentiating and setting the result to zero gives $c=\frac{1}{n}\sum_i y_i$: the sample mean.
\section{Pause and discuss}What changes if large errors should be penalised less strongly? Which assumptions are built into squared error?
\section{Review questions}
\begin{enumerate}\item Explain a residual without a formula.\item Derive the constant least-squares predictor.\item Give an example where the mean is a poor summary.\end{enumerate}
