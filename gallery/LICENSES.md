## Adaptations and assets

- Mimosis: unmodified MIT class; new MIT front matter, chapters, and bibliography.
- Deedy OpenFonts: Apache-2.0 class adapted to bundled font filenames. Raleway Regular
  replaces its ExtraLight/Medium selections. The sample resume is new MIT content.
- SimpleTeX: original MIT formatting definitions and attribution, with new fictional
  CV and letter content. No upstream personal data or photographs are bundled.
- Gemini: MIT theme adapted to load bundled font files by relative path.
- Deedy and Gemini include unmodified Lato and Raleway font binaries under SIL OFL
  1.1, with their copyright/license notices in fonts/*-OFL.txt.
- Tufte, Jake's Resume, and Florilegium retain the upstream notices and editable
  assets listed in each files.txt manifest; sample document text is MIT.
- Kacho: unmodified Apache-2.0 engine, pinned to its full commit; retains LICENSE,
  NOTICE.md (including Florilegium MIT notices), and the upstream API reference.
  New journal content is MIT licensed.
- Mondrian: original MIT Lua vector generator; no reproductions of artwork.
- Flora: unmodified MIT LuaLaTeX package from the official tikzflora.zip download,
  pinned by the archive's SHA-256 (the linked GitHub repository holds the separate
  TypeScript web engine). All 57 Lua modules, the style, boot file, upstream README,
  and copyright/license notices are retained. The three-page garden notebook is
  original MIT content and uses TeX-distributed Latin Modern fonts.
- Calculus Notes: original MIT implementation inspired by the local Calculus1
  project credited to Ludwig Claude Lelis; no original course text is bundled.
  IBM Plex fonts are optional system dependencies with TeX Live fallbacks.
- All other starters are original MIT documents authored for LaTeX Pro. Their
  metadata records a SHA-256 of main.tex; update it when changing the source.

Standard TeX packages are external requirements and are not bundled here.
The license allowlist is enforced in Kotlin and tools/verify_gallery.py --audit-only.
The audit also checks manifests, excluded license declarations, and font notices.
Review upstream file licenses before changing a pin or adding third-party assets.
